# Digital Card — Next.js + Tailwind

## Run

1. Install Node.js.
2. Run `npm install`.
3. Add your image at `public/images/card-front.jpg`.
4. Add your music at `public/music/card-music.mp3`.
5. Run `npm run dev`.
6. Open the local URL shown by Next.js.

## Features

- 3:4 full-bleed photo front
- Tap anywhere on the card to flip
- Tap again to return
- Clean Inter typography
- Looping background music
- Music control in the top-right
- Responsive layout

## Photo

Recommended: 1200 × 1600 px (3:4).

Note: Modern browsers commonly block autoplay with sound until the visitor interacts with the page. The card starts the music on the first interaction if autoplay was blocked.
